# 07 — Stack, About, Contact and CV

**What to build:** The remaining home page sections, completing the page below Selected Work.

**Stack** is an honest grouped list. No proficiency bars, no star ratings, no percentages — a technical Reader treats those as a red flag because the claim cannot be true.

**About** carries the self-taught story: what was built while learning, framed as fact rather than apology, and never claiming experience that does not exist. It includes one honest line about building with AI tooling and being able to explain the decisions it helped reach — one line, placed here, and nowhere else on the site.

**Contact** shows the email as visible text with a one-click copy, alongside GitHub and LinkedIn, the city, and openness to remote or hybrid. There is no contact form and no backend — a form that silently swallows a message is a catastrophic failure during a job search.

**CV** is a static PDF served from the site and versioned alongside it, so it cannot drift from what is deployed.
